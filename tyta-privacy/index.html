Política de Privacidade do Tyta

Última atualização: 7 de maio de 2026

Tyta é um calculador local de rentabilidade para motoristas de aplicativo. Esta política descreve quais dados o app trata, como esses dados são usados e como o usuário pode gerenciar ou remover essas informações.

1. O que o Tyta faz

  • Permite salvar perfis de custo do veículo no dispositivo.
  • Calcula a rentabilidade de corridas localmente no aparelho.
  • Exibe projeções semanais com base nos valores informados pelo usuário.

2. O que o Tyta não faz nesta versão

  • Não cria contas online.
  • Não envia dados do usuário para servidores externos.
  • Não solicita localização, câmera, microfone, contatos, SMS ou armazenamento externo.
  • Não inclui SDKs de anúncios.
  • Não vende dados pessoais.

3. Dados tratados pelo app

O Tyta pode tratar informações fornecidas manualmente pelo usuário, como perfis de custo do veículo, valores de corrida, distância, tempo e demais entradas necessárias para os cálculos.

4. Onde os dados ficam armazenados

Os dados ficam apenas no dispositivo do usuário, em armazenamento local criptografado protegido pelo Android Keystore.

5. Compartilhamento de dados

O Tyta não compartilha dados do usuário com terceiros nesta versão.

6. Retenção e exclusão

  • O usuário pode editar ou sobrescrever os perfis salvos dentro do app.
  • Ao desinstalar o app, os dados locais são removidos conforme o comportamento padrão do Android.

7. Segurança

O app processa os dados localmente, não transmite informações para serviços remotos nesta versão, desabilita backup/restauração automática e mantém os dados locais em formato criptografado.

8. Crianças

O Tyta não foi projetado especificamente para crianças.

9. Contato

Para dúvidas ou solicitações relacionadas a esta política, entre em contato: tavitopstore@outlook.com.
